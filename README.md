# Manav Stays & Hospitality

Next.js website for two properties — Hotel Lalit (Ultra-Luxury) and Hotel Naman (Premium Affordable), Udaipur.

## Setup

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit - Manav Stays website"
git branch -M main
git remote add origin <your-repo-url>
git push -u origin main
```

## Notes

- Put your logo at `public/images/logo.png`
- Built with Next.js 14 (App Router), Tailwind CSS, Framer Motion, lucide-react
